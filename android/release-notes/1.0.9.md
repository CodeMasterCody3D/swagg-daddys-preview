Install this update over the existing owner app.

- Keeps the Android camera permission declared and requests access for live VIN scanning on the trusted Swagg Daddys website.
- Obtains Android camera consent before asking WebView to open the camera, so its permission dialog cannot cancel the camera request. Enables the muted live preview after consent.
- Clears a downloaded update once that version (or a newer one) is already installed, so the same update popup does not return on every launch.
- Keeps the original app identity, release signing key, Firebase notification configuration, and all three VIN readers.

After installation, open Tools → Live scan VIN and allow camera access when Android asks. Check camera scanning on the phone after installing.
