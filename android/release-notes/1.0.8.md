Install this APK over the existing owner app.

- Enables live VIN scanning in owner Tools with a camera permission prompt when you start scanning.
- Adds VIN photo selection from the phone's image picker.
- Limits camera access to the trusted Swagg Daddys website; microphone access stays blocked.
- Retains the existing app identity, Firebase settings, original signing key, and push notifications.

The website keeps barcode, Google Lens, printed-text recognition, crop/retry, zoom and flashlight controls. A scan only succeeds after clean year, make and model details are returned. Failed scans show red Try again feedback.

Physical-phone camera and notification delivery should be checked after installing.
